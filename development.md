## Clone module or repository

```shell
git clone git@github.com:TASCB/openimis-fe-grievance_social_protection_js.git
cd openimis-fe-grievance_social_protection_js
git checkout tz-changes
yarn install
yarn build
yarn start # For development
yarn link
yarn unlink "@openimis/fe-grievance_social_protection"
```

## Remove pre-existing

```shell
yarn remove @openimis/fe-grievance_social_protection
```

## Link

```shell
cd ../openimis-fe_js
yarn link "@openimis/fe-grievance_social_protection"
```
